# BLUE WHALE PRO — Crypto Spot Scanner

Free local test build using Binance public Spot market data. No API credentials are embedded.

See `START_HERE.txt` for simple Windows setup steps.

Official market-data documentation:
- https://developers.binance.com/en/docs/products/spot/faqs/market_data_only
- https://developers.binance.com/en/docs/products/spot/rest-api

The 10-pair watchlist is a fixed starter basket, not a live top-10 market-cap list.
